# Portfolio Assets & Documentation

A centralized repository for hosting, organizing, and managing image assets and project documentation for my personal portfolio.

---

## 📌 Features & Usage

* **Asset Management:** Clean folder structure for high-resolution project screenshots, diagrams, and media.
* **Documentation:** Design specs, project write-ups, and architectural notes.
* **Easy Linking:** Direct image hosting and paths for easy integration into web applications or markdown files.

---

```text
├── assets/
